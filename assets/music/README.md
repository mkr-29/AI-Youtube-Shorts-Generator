# Background Music Directory

Drop any copyright-free `.mp3` or `.wav` background music tracks here (e.g. lofi, ambient suspense, upbeat edutainment).

When any audio file is placed here:
- The video engine automatically picks a random track.
- Seamlessly loops it to match the exact video length.
- Ducks the volume to 8% so the voiceover stays clear and intelligible.
- Mixes it into the final render.

If this directory is left empty, the video renders with speech only.
